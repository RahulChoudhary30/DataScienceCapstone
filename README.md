# SpaceX Falcon 9 First Stage Landing Prediction (IBM Applied Data Science Capstone)

Goal: predict whether the Falcon 9 first stage will land successfully, so the cost of a launch can be estimated.

| # | Notebook | Content |
|---|----------|---------|
| 1 | `01_spacex_data_collection_api.ipynb` | Data collection with the SpaceX REST API |
| 2 | `02_spacex_data_collection_webscraping.ipynb` | Data collection by scraping Wikipedia |
| 3 | `03_data_wrangling.ipynb` | Cleaning, landing outcome label `Class` |
| 4 | `04_eda_with_visualization.ipynb` | EDA with Matplotlib/Seaborn, feature engineering |
| 5 | `05_eda_with_sql.ipynb` | EDA with SQL (10 queries) |
| 6 | `06_interactive_map_folium.ipynb` | Folium launch-site map and proximity analysis |
| 7 | `07_predictive_analysis.ipynb` | LR, SVM, Decision Tree, KNN with GridSearchCV |
| - | `spacex_dash_app.py` | Plotly Dash dashboard |

Run the notebooks in order in the IBM Skills Network lab (or locally), then commit them **with outputs**.
